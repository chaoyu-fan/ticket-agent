# 大麦优先实施计划

## 用户默认策略

目前没有活动链接、数量、票档和预算，因此采用保守默认值：一张票、所有可见票档中最低价优先、未设置最高总价时不自动提交订单。用户以后可以在计划中显式设置 `maxTotalFen` 和观演人本地别名，再开启 `autoSubmitOrder`。

## 里程碑

1. **已完成**：核心控制器、计划 CRUD、SQLite 审计、不可变价格快照、一次性提交批准和跨平台重复购买锁。
2. **已完成**：macOS 独立 Chrome 配置、手动登录边界以及 dry-run/mock/live 三种显式模式。
3. **仿真完成、真实适配待链接**：大麦 UI-only 适配器；队列、验证码、登录失效、售罄、重定向、价格变化和页面改版全部 fail-closed。
4. **调度仿真完成、真实演练待链接**：远期开售保持 `SCHEDULED`，进入 10 分钟预热窗口后等待 `saleAt`，官方队列仅同页串行轮询；仍需使用用户提供的低热度官方活动完成确认页演练。
5. **待完成**：猫眼独立适配器；复用安全接口，但不共享大麦选择器或账号会话。

## 为什么不把浏览器放在服务器

账号会话、实名观演人和设备网络更适合留在用户的 Mac 上。控制器也默认运行在 Mac loopback；当前服务器只保存开发工程，不安装浏览器镜像，也不触碰现有 OpenClaw/WeCode 服务。

## 开发和上线边界

- 不逆向私有 API，不破解验证码，不使用代理池或多账号并发。
- 页面出现验证、异常价格或未知结构时停止，不猜测点击。
- 真实购买成功率由库存和官方队列决定，验收指标是状态正确、预算不越界、无重复提交和可人工接管。
